<objective>
Poser le socle base de données de la phase 1 (D-10) et le prouver sur un PostgreSQL 18 réel (QUAL-08) : rôles séparés migrations / app (le rôle de migration est provisionné hors migration, puisqu'il exécute les migrations ; la première migration SQL forward-only, jouée sous ce rôle, crée le rôle app, le schéma et les privilèges), exécution par le `Migrator` de Kysely sous le rôle de migration, tests d'intégration sur Testcontainers en ordre aléatoire, méta-tests posés dès maintenant (RLS sur `owner_member_id`, rôle app sans DDL), check `integration` dans la gate, et check `coverage` qui applique le plancher global de couverture à tout `src/**`, infrastructure base de données comprise, sur un run fusionné `unit` + `integration` (décision humaine).

Purpose: les invariants du produit vivent en SQL ; seul un vrai PostgreSQL le prouve. Les méta-tests existent avant la première table métier pour qu'aucune table future n'y échappe.
Output: `db/migrations/0001_foundation.sql`, `src/db/{sql-migration-provider,migrate}.ts`, `test/{global-setup,db}.ts`, `test/{foundation,meta}.int.test.ts`, projet Vitest `integration`, checks `integration` et `coverage`.
</objective>
