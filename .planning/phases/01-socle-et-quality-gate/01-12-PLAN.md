Format d'un cas (plan 01-10), `quality/selftest/cases/<id>/` : `expected.json` = `{ "check": "<id du check>", "rule": "<règle attendue>", "install": "frozen" | "link" }`, puis **soit** `patch` (diff unifié appliqué par `git apply --index`), **soit** `apply.ts` (export par défaut `apply(root: string): Promise<void>`, échec « case-stale » si sa cible a disparu). Runner : `node quality/selftest/run.ts --case <globs> --report <fichier>`. Règles attendues : `sast` → `prosperity.<id>` (correspondance par suffixe) ; `workflow-audit` → `unpinned-uses` ; `cve` → `GHSA-…` ; `unit` → `coverage-threshold` ; `mutation` → `mutation-score-below-break` ; `escape-hatches` → le motif ; `integrity` → `assertion-removed`, `protected-path-changed`, `supply-chain-policy-weakened` ; `integration` → `meta:rls-owner-member-id` ; `deps` → `dependency-added`. Les checks `integrity` et `deps` jouent en local quand `GATE_BASE_DIR` est défini (le runner le pose sur le worktree propre, labels approuvés vides).

Canari (plan 01-03) : `allocate(total: Money, weights: readonly bigint[]): Result<Money[], 'invalid-weights'>`, `Money` = `{ amountMinor: bigint; currency: 'EUR' }` ; tests de `allocate.ts` uniquement dans `src/shared/money/allocate.test.ts` (exemples) et `src/shared/money/allocate.properties.test.ts` (Σ parts = total, écart < 1 centime). Le check `mutation` mute les fichiers mutables du diff, plus le source colocalisé de chaque test modifié ; un fichier supprimé n'ajoute aucun source.
